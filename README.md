# 레서담 - PDF 변환 합치기

레서담은 이미지·한글·워드·엑셀·파워포인트를 PDF로 바꾸고, 정한 순서대로 합치는 Windows 프로그램이에요.
빌드된 EXE의 **PDF 합치기와 이미지 변환은 Python·한글·Office 설치 없이 실행할 수 있어요.**
한글·Office 문서를 바꾸려면 해당 데스크톱 프로그램이 PC에 설치되어 있어야 해요.
현재는 로컬 검토 단계이며, 공개 배포본은 아직 없어요.

## 탭 세 개

| 탭 | 하는 일 | 결과 |
| --- | --- | --- |
| ① PDF로 바꾸기 | 파일마다 PDF를 하나씩 만들어요 | 파일 N개 → PDF N개 |
| ② 하나로 합치기 | PDF·이미지·문서를 목록 순서대로 이어 붙여요 | 파일 N개 → PDF 1개 |
| ③ 폴더끼리 짝지어 합치기 | 폴더마다 같은 순서의 파일을 하나씩 모아 합쳐요 | 줄마다 PDF 1개, 또는 모두 이어서 PDF 1개 |

③ 예) `한글\가.pdf + 영어\A.pdf + 숫자\1.pdf` → 첫 번째 PDF, `나 + B + 2` → 두 번째 PDF …

## 바꿀 수 있는 파일

- 이미지: jpg, png, bmp, gif, tif(여러 쪽 포함), webp
- 한글: hwp, hwpx
- 워드: doc, docx, rtf, odt, txt 등
- 엑셀: xls, xlsx, xlsb, ods 등 (시트마다 정해 둔 인쇄 설정대로)
- 파워포인트: ppt, pptx, odp 등

| 처리 | PC에 필요한 프로그램 |
| --- | --- |
| PDF 합치기, 지원 이미지의 PDF 변환 | 이 프로그램만 필요 |
| hwp / hwpx | 자동화 기능을 제공하는 한컴 한글 데스크톱 버전 |
| doc / docx / rtf / odt / txt 등 | Microsoft Word 데스크톱 버전 |
| xls / xlsx / xlsb / ods 등 | Microsoft Excel 데스크톱 버전 |
| ppt / pptx / odp 등 | Microsoft PowerPoint 데스크톱 버전 |

문서는 해당 프로그램의 COM 자동화로 PDF를 내보내요. 웹 버전·뷰어만 설치된 환경은 지원하지 않아요.
한글·Office와 폰트는 이 EXE에 포함되지 않으며, 별도로 적법하게 설치·사용해야 해요.
한글·PowerPoint가 이미 열려 있으면 작업 중인 문서를 보호하기 위해 닫은 뒤 다시 시도하도록 안내해요.
Word·Excel은 별도 인스턴스를 사용해요.
암호 문서는 변환하지 않아요. ①·③의 여러 결과 만들기는 실패한 파일/묶음을 제외하고 계속하고,
②·③의 하나로 만들기는 파일 하나라도 변환하지 못하면 결과를 저장하지 않아요.

한글은 파일 위치와 설치 설정에 따라 '파일에 접근하려는 시도가 있습니다' 창을 띄울 수 있어요.
처리하려던 문서가 맞는지 확인하고 직접 허용 여부를 선택하세요.
어떤 프로그램이든 확인 창을 띄우면 그 창을 앞으로 꺼내고 아래 상태 줄에 알려요. 멈추려면 **중지**를 누르면 돼요.

## 할 수 있는 것

- **정렬 기준…**: 이름, 수정한 날짜, 만든 날짜, 찍은 날짜(사진), 크기, 종류, 쪽수, 폴더 위치 — 오름차순·내림차순.
  목록 맨 위의 **파일 이름·쪽·크기·수정한 날짜·폴더** 열 제목을 눌러도 그 기준으로 정렬돼요.
  같은 열을 다시 누르면 반대 방향으로 정렬되고, ▲·▼로 방향을 표시해요. 순서·회전 각도 열은 정렬 버튼이 아니에요.
  정렬하면 실제 처리 순서도 바뀌어요. 위·아래 이동 버튼으로 순서를 바꿀 수도 있고, 목록의 줄을 끌어서는 순서가 바뀌지 않아요.
- **오른쪽 90° 회전**: 목록에서 고른 파일의 모든 쪽을 시계 방향으로 90° 회전해 출력해요 (원래 파일은 그대로).
  오른쪽 클릭 메뉴에서는 왼쪽 90°·180° 회전과 회전 각도 초기화도 할 수 있어요.
- **이미지 넣는 방법**: A4에 맞춤 / 원본 크기, 용지 방향 자동·세로·가로,
  방향이 다른 이미지는 90° 눕혀서 크게 넣기. 자동이면 가로로 긴 이미지는 가로 A4가 돼요.
- **저장할 파일 이름** (①·③): 앞에 붙일 말 + (원래 이름 / 원래 이름에서 구간 선택) + 뒤에 붙일 말 + 번호.
  앞뒤 문구는 자동으로 공백을 넣지 않고 입력한 그대로 붙여요.
  `통합` + `도면` → `통합도면`, `통합 ` + `도면` → `통합 도면`. 띄어쓰기가 필요하면 직접 입력하세요.
  '원래 이름에서 구간 선택'을 고르면 이름들을 띄어쓰기 단위로 나눠, 모든 이름에 똑같은 구간(회색)과
  이름마다 다른 구간(파란색)을 체크칸으로 보여 줘요. 체크한 구간만 이름에 들어가요 (처음엔 다른 구간만).
  똑같은 구간이 앞·가운데·뒤 어디에 몇 개 있어도 돼요.
  예) `가상도 예제시 샘플구 가상가동 143 토지대장 9001 시험.pdf` → 다른 구간만 남기고 앞에 `통합 ` → `통합 가상가동 143 9001.pdf`
  번호는 앞/뒤 위치·시작 번호·자릿수와 **번호와 이름 사이**에 넣을 문자를 정할 수 있어요.
  공백, 마침표와 공백, `_`, `-`, 없음 중에서 고르거나 직접 입력하세요.
  예) `01. 도면.pdf`, `도면_01.pdf`, `001 - 도면.pdf`. ②·③의 사용자 지정 책갈피 이름에도 적용돼요.
- **②의 저장**: 화면 아래의 **저장할 폴더**와 **파일 이름**을 정한 뒤 **합쳐서 저장**을 눌러요.
  처음 이름은 파일들의 같은 앞부분 + `_합본.pdf`로 채워 두며, 직접 입력한 이름은 목록이 바뀌어도 유지해요.
- **책갈피** (②·③): 합친 PDF의 책갈피 칸에서 파일마다 바로 찾아갈 수 있어요.
  이름은 원래 파일 이름 / 폴더 이름 / 사용자 지정 이름 규칙 / 달지 않음 중에서 골라요.
  '사용자 지정 이름 규칙'을 선택하면 [이름 규칙 정하기…] 버튼이 활성화돼요.
  이 창에서 이름 짓기와 같은 방식으로 정하고 미리 볼 수 있어요. 다른 방식을 선택하면 버튼이 비활성화돼요.
- **③ 만들 PDF**: 줄마다 PDF 하나씩(N개) 또는 모두 이어서 PDF 하나(1개).
  하나로 만들면 줄마다 책갈피(예: `가상가동 143`)를 달고, 그 아래에 파일 책갈피를 넣어요.
- **③의 개수가 다를 때**: 폴더마다 파일 수가 다르면 어디부터 비는지 알려 주고,
  "모든 폴더에 파일이 있는 데까지만" 또는 "끝까지(없는 파일은 빼고)" 중에서 골라요.
  미리 보기 표에서 줄마다 만들지 말지도 정할 수 있어요.
- 같은 이름의 PDF가 이미 있으면 덮어쓸지, 이름 뒤에 (2)를 붙일지 물어봐요.
- 파일·폴더를 창에 끌어다 놓거나, exe 아이콘에 끌어다 놓아 열 수 있어요 (② 탭으로 들어가요).

## 개발 환경에서 실행

```
py -3.14 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py
```

## 점검

```
.venv\Scripts\python tools\make_samples.py
.venv\Scripts\python tools\check.py
.venv\Scripts\python tools\check_safety.py
```

`make_samples.py`는 **비어 있는** `scratch\samples`에 가상 이미지·문서·폴더를 만들어요.
기존 폴더가 차 있으면 덮어쓰지 않으므로 새 경로를 인수로 주세요. 실제 주소·업무 자료를 샘플로 사용하지 않아요.
문서 작성자 메타데이터는 생성 시 제거해요. 문서는 이 PC의 한글·오피스로 만들어서,
한글이 접근 확인 창을 띄우면 직접 확인해야 해요. `check.py`는 이미지 방향, 이름 짓기, 폴더 짝짓기, 문서 변환, 합치기·중지를 확인해요.
`check_safety.py`는 중지·저장 실패 때 기존 파일 보존, 동시 저장의 임시 파일 분리, 프로세스 소유권 확인을 점검해요.
샘플·변환 결과·시험 로그는 `scratch/`에만 두며 Git 추적과 EXE 포함 대상에서 제외해요.

## exe 만들기

```
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python tools\build_exe.py
```

`dist\lesserdam\레서담 - PDF 변환 합치기.exe`가 생겨요.
EXE와 실행 창 모두 레서판다 `assets/app-icon-v3.ico`를 사용해요.
점검 후 원하는 폴더로 빌드하려면 `--dist <폴더>`를 지정하세요.
라이선스 원문·고지와 SHA-256 파일도 같은 폴더에 만들어요.

## 처리 범위와 주의할 점

- 앱 소스에는 파일 업로드·분석 전송 기능이 없어요. 외부 문서 앱의 연결 기능·통신까지 통제하는 것은 아니에요.
- 원본 문서를 수정하지 않고 읽어 변환해요. PDF에 작성자 정보·주석·링크가 남을 수 있어요.
  **PDF 변환은 개인정보 삭제나 문서 무해화 기능이 아니에요.** 신뢰하는 파일만 처리하세요.
- 합친 PDF에는 선택한 파일/줄 책갈피를 새로 만들어요. 원본 PDF의 기존 책갈피·전자서명·양식 동작을
  그대로 보존하는 용도가 아니며, 전자서명 유효성은 합치기 후 유지되지 않아요.
- 문서의 글꼴·용지·인쇄 영역과 한글·Office 버전에 따라 출력이 달라질 수 있어요. 결과를 확인하세요.
- 변환 캐시는 Windows 임시 폴더에 생겨요. 정상 종료 때 지우지만 강제 종료·전원 차단 때 남을 수 있어요.
- 폴더끼리 짝짓기는 **각 폴더의 정렬 순서**를 기준으로 해요. 같은 파일명을 찾아 연결하는 방식이 아니므로
  미리 보기에서 줄마다 맞는 파일인지 확인하세요.
